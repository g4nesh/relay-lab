# Archived Fetch integration

The Fetch/Agentverse/ASI:One integration was removed from Relay Lab's active
runtime at the user's request. These sources and historical tests are retained
for reference, outside the installed Python package and default test suite.

Current runs use a local LLM mediator, simulator-grounded outcome checks, and
SpacetimeDB. They do not require a Fetch account, SDK, mailbox, or API key.
Private historical account identities remain in the ignored `.relay-lab/`
directory; no account or remote profile was deleted.
